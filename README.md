Algoritma: Long Short-Term Memory (LSTM)

Judul Proyek

Implementasi Long Short-Term Memory (LSTM) untuk Klasifikasi Sentimen Ulasan Pelanggan Hotel Menggunakan Dataset Trip Advisor.

Dataset

Dataset yang digunakan adalah Trip Advisor Hotel Reviews yang diperoleh dari Kaggle.

Sumber dataset: https://www.kaggle.com/datasets/andrewmvd/trip-advisor-hotel-reviews

Metode

Penelitian menggunakan algoritma LSTM untuk mengklasifikasikan ulasan hotel menjadi tiga kategori sentimen:

- Negatif
- Netral
- Positif

Hasil Pengujian

- Accuracy: 77,72%
- Macro-F1 Score: 63,37%
- Jumlah data awal: 20.491 ulasan

Tools

- Python
- Google Colab
- PyTorch
- Pandas
- Scikit-learn
- Matplotlib

Cara Menjalankan

1. Buka notebook ".ipynb" menggunakan Google Colab.
2. Jalankan seluruh cell secara berurutan.
3. Unggah dataset Trip Advisor dalam format CSV atau ZIP ketika diminta.
4. Tunggu hingga pelatihan dan evaluasi selesai.
5. Periksa grafik serta hasil evaluasi model.
